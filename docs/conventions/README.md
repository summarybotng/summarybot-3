# Agent & contributor conventions

Durable working agreements for this repo — for both human contributors and AI
coding agents (Claude Code et al.). One convention per file, so they're easy to
add, review, and cite in a PR.

This folder is the **source of truth** for conventions because it's committed to
git: it survives Codespace rebuilds, is shared with everyone, and shows up in
code review. (By contrast, an agent's `~/.claude/.../memory/` notes are
per-environment and are lost on a container rebuild, and the `.claude/` folder
here is gitignored and regenerated by `ruflo init`.)

`CLAUDE.md` points agents here; treat every file below as binding.

## Conventions

- [Always browser-check the UX](always-browser-check-ux.md) — after any `web/`
  change, visually verify the running UI in a browser, not just build + curl.
- [Keep the coverage map current](keep-coverage-map-current.md) — update
  `docs/coverage-map.md` in the same commit when a feature's status changes.
- [Keep the product docs current](keep-product-docs-current.md) — update the
  `docs/product/` set (mission/vision, capabilities, functional areas, roles &
  user stories, user guide) in the same commit when the product surface changes.

## Adding one

Create `docs/conventions/<kebab-name>.md` with: the rule, **why** it exists
(ideally the incident that prompted it), and **how to apply** it concretely.
Add a line to the list above.
