# Project conventions (durable)

> This lives in `CLAUDE.local.md`, not `CLAUDE.md`, on purpose: `CLAUDE.md` is
> **generated/regenerated by ruflo/claude-flow** (`ruflo init`, the `claude-flow`
> MCP server, hook invocations), so any hand-added lines there get overwritten
> back to the template. `CLAUDE.local.md` is read by Claude Code but not managed
> by ruflo, so instructions here survive.

- Follow the project conventions in `docs/conventions/` (committed, durable) —
  e.g. always browser-check the UX after a `web/` change. Read that folder before
  substantial work and add to it when a new working agreement emerges.
